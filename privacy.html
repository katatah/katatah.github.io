プライバシーポリシー

最終更新日: 2026年9月29日

対象

このポリシーは、個人用ツール「科学ニュース動画 自動投稿ツール」（以下、本ツール）に適用されます。本ツールは運営者本人の YouTube チャンネルへの動画投稿にのみ使われます。

取得する情報と利用目的

本ツールは Google の OAuth を通じて YouTube Data API の「動画のアップロード」権限（youtube.upload）だけを使い、運営者のチャンネルに動画をアップロードします。視聴者や第三者の個人情報は取得しません。

保存と共有

認証に必要なトークンは、運営者が管理する非公開の環境に暗号化して保存し、動画のアップロード以外には使いません。第三者に提供・販売することはありません。

権限の取り消し

Google アカウントのサードパーティのアクセス管理から、いつでも本ツールの権限を取り消せます。

本ツールによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
